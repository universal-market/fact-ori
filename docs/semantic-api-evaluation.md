# Semantic API release evaluation

This is an authored regression diagnostic for the seven-record library, not a
held-out benchmark, independent factual review, or general accuracy estimate.
The implementer wrote the cases and prompts and observed earlier failures.
Prompt examples overlap the cases. Technical reviewer Factfinder and implementer
Factomaton share Adrian ownership. Existing source reviews and source dependence
remain attached to their original frozen packages.

The real-model runner checks paraphrased units/capital/election questions,
conflicting capital/numeric assertions, changed property/medium/year,
package-limited abstention, ambiguity, missing coverage, a mixed paragraph and a
compound sentence. The research case opts into a real durable job. Its status
check alone does not verify posting, review, or research completion.

Record complete results, timings, exact source/model/import bindings and failures.
Preserve prior failed/partial attempts separately. Do not change expected labels
to make a failed model pass. Passing these cases does not show that the extraction
auditor or relationship model never omits, misreads or overgeneralizes.

Public release verification separately checks actual HTTPS paragraph submission,
status reads, pinned evidence, opted-in research deduplication, the linked Tilori
post/revision/recorder, OpenAPI and blocked administration paths. Research task
status and factual approval are distinct. C011 is an unapproved Venus draft and
is excluded from this fixed seven-record evaluation.

Run the isolated stack from a trusted checkout, then:

```sh
node scripts/evaluate-semantic-api.mjs ORIGIN REPORT.json
node scripts/verify-semantic-deployment.mjs HTTPS_ORIGIN REPORT.json RECEIPT.json
```

The second command requires all 14 real-model cases to pass and the research job
to have a linked, observed Tilori status. It uses only the public API. Ordinary
operator claim/link/reconciliation receipts remain separate. The scripts do not
establish cryptographically authenticated runtime build/review attestation.

Run the Python, Convex, semantic/HTTP/client and real-nginx regression suites too.
Those consistency/lifecycle tests do not establish factual truth. Paragraph
source offsets use JavaScript UTF-16 positions. All inferred relationships and
extraction audits remain explicitly model-assessed. Local CPU inference can take
minutes; the public API returns durable asynchronous progress rather than holding
an HTTP connection until all claims finish.
