# Proposed Q7 candidate real-model diagnostic protocol v1

This frozen proposal closes the scope gap left by the successful deterministic-stub HTTP smoke. It proposes two sequential actual-engine cases using the cached pinned real models: a Canberra paraphrase must return the exact C004/v1 evidence package, and a currently uncovered Gold question must return missing coverage with no answer, verdict, job or public submission. Labels are frozen before execution. These are exposed authored diagnostics, not a held-out accuracy estimate.

`data/W015-Q8-real-model-protocol-v1/protocol.json` pins source, candidate/inference images, engine fingerprint, model digests, approved eight-record snapshot and exact expectations. `review-input.json` binds that proposal, prior smoke receipt and all18source/4active inputs by raw SHA256. The backend is explicitly a strict snapshot fixture forcing the semantic path, so this scope would measure actual model/engine behavior without claiming actual Convex, HTTP, research intake or publication verification.

The proposed run uses its own isolated containers/internal network, no published port or external egress, only credential-free cached model content mounted read-only, ephemeral state, serial work and hard CPU/memory/PID/time limits. There is no inference launch this cycle. Exact safe mount mechanics, cached image/model availability and resource headroom are unresolved preflight gates, never assumed from this protocol. Whole inference homes/volumes and shared production services are excluded. No automatic pull, retry or polling loop is permitted; sanitized partial failure and cleanup are required.

Q8 requests exact protocol review only. It does not request model execution, source edits, harness implementation or deployment. After mutual assent, the reviewer submits accept/revise/unresolved and exact input bindings through a new free Market Task; separate recipient assessment follows. Later implementation/preflight and execution each need their own bounded scope. Completed Q7 and its prior structural acceptance are retained unchanged.

No independent-owner, blinded, held-out, non-author curation, new factual/source acceptance, production readiness or API publication approval follows.
