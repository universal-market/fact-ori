# Offline actual-engine worker and exact result validator v1

This component imports the unchanged actual `FactEngine`, initializes all eight approved snapshot records in memory SQLite, and runs both frozen Q8 inputs. Deterministic model callbacks supply two authored embedding directions, atomicity judgments and relationship judgments. A strict in-memory backend fixture forces the semantic path, rejects consent true and unknown paths, and revalidates exact record/version/hash pins. No HTTP server, `ModelClient` or real inference is used.

`loadInputs` checks the frozen protocol raw digest before using its snapshot path, then exact snapshot bytes/import, model pins, engine fingerprint and eight-record count. `validateCase` re-reads these fixed inputs rather than accepting caller-supplied expectations. It checks exact text, single verbatim claim/span, model revisions, top-level and row labels/answer/verdict, null jobs/no submission, C004 inspection and full evidence-package equality/digest, or absence of inherited Gold evidence. This is a finite checker for these two exposed cases, not a general model-output security validator or factual review.

Run `node scripts/diagnostic-worker.test.mjs` for 18 checks, including altered label/answer/verdict/import/revision/span/claim count/record pin/package/review attribution/job/submission and unexpected Gold evidence, plus backend consent and pin rejection. Run `python -B data/W015-Q10-worker-v1/parent-probe.py` for the actual accepted supervisor spawning the fixture-only worker, receiving startup and two ordered case events, checking zero exit and byte-equal saved fixture results. The receipt records observed Node v25.2.1; repeat-byte comparison is scoped to that environment. This is not a measurement of the pinned Node22 candidate image.

The CLI accepts only `--fixture OUTPUT`, uses fixed repository inputs and memory state, writes a fresh output file without overwrite, and emits phase metadata to stdout. It returns a fixed failure diagnostic without stack/error details. It has no live endpoint/model-origin/environment switch. Its saved report includes complete public fixture results, not sanitized arbitrary model output; full partial-answer preservation/sanitization and failure-report integration remain unfinished. Metadata alone never proves semantic success.

The initial unpublished test used identical vectors for every record, so the engine's top-two tie excluded C004 and the validator failed. The fixture was corrected to distinguish the capital direction while preserving both frozen labels and every production input. No engine/protocol change or real-model failure is implied. The first `node --test` invocation reported one file-level item; the direct test-module invocation exposes and passes all18 registered checks.
