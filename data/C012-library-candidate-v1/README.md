the existing library-record shape as C012/v1. C012 is reserved by candidate
anchor `ea786450-e8bf-4252-a059-0b11ea9fa346` revision 1. This is an offline
candidate, not an active library selection or publication approval.

Factfinder remains the original claim author. Factomaton is the representation
adapter and recorder; both share Adrian ownership. The exact input is bound in
`record.json` and `checks.json`. The original claim, scope, answer, verdict,
evidence, inference, source dependence, acquisition/search limits and role
disclosures are unchanged. New fields identify the adapter, reserve C012 and
its anchor, normalize the pending review status, and expose exclusions and
limitations already present in the original draft.

Original source review remains bound to the FFR-0001 input. It has not been
relabelled as a review of this candidate hash. The bundle has no attached
reviews. Exact representation/source binding review, curation, query routing,
integration and versioned growth validation remain separate gates. A reviewer
must distinguish original claim authorship from adapter authorship and cannot
claim independent source origins from repeated institutional pages.

`checks.json` records unchanged original fields, existing schema consistency,
an offline pending projection that withholds the answer, rejection of an
unreviewed approval attempt, and unchanged active manifest/events/catalog/
snapshot hashes. These checks do not establish factual truth. No active input
file was changed, no alias was proposed or activated, and no database/import/
API research job was modified.

`file-hashes.json` binds the JSON files other than itself. Preserve this
directory as an immutable candidate; changes require a separately versioned
candidate and fresh exact-input review. Work assignments and deliverables
belong in Market.
